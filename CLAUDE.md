# ARIA — guide for AI coding agents

ARIA (*Adaptive Reasoning & Intelligent Assistant*) is Miller's independent fork, based on Coucou by Louis Raille (MIT). Work happens on Windows, in `windows/` — the Tauri app. `NotchBuddy/` is the original macOS app (Coucou): it stays as a reference and is not modified.

ARIA lives at the top of the screen. She shows AI coding agent sessions (Claude Code, Cursor, Codex, Gemini CLI, Antigravity), lets the user approve, answer, chat and drop files, and is a full assistant: several AI providers (Anthropic, xAI Grok, OpenAI, Google, Ollama, LM Studio), local tools, MCP connections, skills she writes herself, and changes to her own code under supervision. The name is always written ARIA, in capitals; she is referred to in the feminine.

## Where things are
- `windows/src-tauri/` — Rust: `pipe.rs` (relay server), `hooks.rs` (agent hook installers), `providers.rs` (AI APIs), `agent.rs` (tool loop), `tools/` (local tools), `policy.rs` (approvals and audit), `mcp.rs` (MCP client), `selfmod/` (core guard, skills, self-evolution), `migrate.rs` (the one-time copy from Coucou).
- `windows/src/` — TypeScript, no framework: island, views, settings window, the character in `aria/`.
- `windows/hook/` — the `aria-hook` relay every agent's hooks call.
- `windows/core-directive.md` — ARIA's core directive. Protected.
- `NotchBuddy/Sources/CoucouKit/PillCatalog.swift` — pill IDs, names and colours (reference for `windows/src/core/state.ts`).
- `docs/AGENTS.md`, `windows/README.md` — agent integrations and Windows specifics.

## Build
```
cd windows && npm install && npm run tauri dev
cargo test --workspace        # from windows/
npx tsc --noEmit              # from windows/
```

## Rules
- No third-party dependencies unless truly unavoidable. The character is drawn in code, no Rive/Lottie/images.
- Secrets live in the Windows Credential Manager, never on disk or in git.
- No telemetry. Network calls only to services the user configured.
- Never block an agent: if the app doesn't answer, the hook exits immediately and the agent asks in its own UI.
- Never overwrite an agent's config (`~/.claude/settings.json`, `~/.cursor/hooks.json`, `~/.codex/hooks.json`, `~/.gemini/settings.json`): dated backup, merge, show the diff, write only after the user confirms.
- Nothing with side effects happens without an explicit click: sending an email, approving an agent's permission, running a command, writing a file, opening an app, installing a skill, applying a change to ARIA's own code.
- The protected core cannot be changed by ARIA herself: `windows/core-directive.md`, `policy.rs`, `secrets.rs`, `pipe.rs`, `migrate.rs`, `selfmod/`, `hook/`, `tauri.conf.json`, `capabilities/`, this file. Only a human edits them.
- Every tool call the assistant makes is written to the audit log (`aria.log`).
- Performance: 0 % CPU when the island is hidden.
- The identifier is `dev.miller.aria` (Credential Manager service, webview data). Coucou's `fr.louisraille.coucou` is only read by `migrate.rs`, and Coucou's keys are deleted only from the button in Settings.
- Hooks installed by Coucou (`coucou-hook`, `coucou_agent`, "generated by Coucou") are still recognised, so they can be found, updated and removed: keep accepting them.
- Pill IDs are stable contract values (Credential Manager, settings, hook routing): never rename an existing pill ID.
- New views follow the existing app style.
- No public release or installer until the character, sounds and icons inherited from Coucou are redrawn or licensed: renaming does not settle that. Keep the upstream MIT notice and the credit "Based on Coucou by Louis Raille".
